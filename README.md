# 🖨️ מדפסת וירטואלית — Virtual Printer

תוכנת Windows לניהול הדפסות מהירות עם ממשק גרפי נאה בעברית.

---

## 📁 תוכן התיקייה

```
VirtualPrinter/
├── VirtualPrinter.exe          ← התוכנה הראשית (הפעל אותה)
├── INSTALL_PRINTER.bat         ← התקנת המדפסת הווירטואלית
├── UNINSTALL_PRINTER.bat       ← הסרת המדפסת
├── README.md                   ← קובץ זה
│
│   (לפיתוח מקוד מקור בלבד:)
├── main.py                     ← קוד ראשי
├── ui_components.py            ← רכיבי ממשק
├── settings_manager.py         ← ניהול הגדרות
├── print_engine.py             ← מנוע הדפסה
├── hebrew_date.py              ← חישוב תאריך עברי
├── printer_installer.py        ← מתקין מדפסת Windows
├── setup.py                    ← בנייה ל-exe
└── requirements.txt            ← תלויות Python
```

---

## 🚀 הפעלה ראשונה

### שלב 1 — הפעל את התוכנה
לחץ פעמיים על **`VirtualPrinter.exe`**

### שלב 2 — התקן את המדפסת הווירטואלית
לחץ פעמיים על **`INSTALL_PRINTER.bat`**  
אשר את הרשאות מנהל המערכת (UAC).

> ✅ לאחר ההתקנה, **"מדפסת וירטואלית"** תופיע ברשימת המדפסות של כל תוכנה ב-Windows.

---

## 🖨️ שימוש

### א. שליחה מתוך תוכנה אחרת (Word, Chrome וכו')
1. בכל תוכנה, לחץ **הדפס** (Ctrl+P)
2. בחר **"מדפסת וירטואלית"** מרשימת המדפסות
3. לחץ **הדפס**
4. חלון המדפסת הווירטואלית ייפתח עם אפשרויות הדפסה
5. בחר סוג הדפסה ולחץ **"הדפס עכשיו"**

### ב. פתיחה ישירה (ללא שליחה ממקום אחר)
- **גרור קובץ** לחלון התוכנה הפתוח
- **או** לחץ **"📂 בחר קובץ"** בחלון הפתוח

## ⚙️ הגדרות

לחץ **⚙️** בחלון הראשי.  
סיסמת ברירת מחדל: **1234**

### לשונית "אפשרויות"
- הוסף/ערוך/מחק אפשרויות הדפסה
- לכל אפשרות: שם בעברית ואנגלית, תיאור, אייקון
- אפשרות לצרף תמונה מותאמת אישית (PNG/JPG)

### לשונית "מתגים"
- ניהול מתגי ההדפסה (דו-צדדי, היפוך, ימין-שמאל וכו')
- הוסף מתגים מותאמים אישית

### לשונית "מדפסות"
- הגדר מדפסת ברירת מחדל
- הגדר מדפסת שונה לכל סוג הדפסה
- הצג/הסתר בחירת מדפסת בחלון הראשי

### לשונית "תאריך"
- תאריך עברי בלבד / לועזי בלבד / שניהם

### לשונית "אבטחה"
- שנה סיסמה / אפס ל-1234 / הסר סיסמה

## ❓ שאלות נפוצות

**ש: המדפסת לא מופיעה ב-Word / Chrome?**  
ת: הרץ מחדש את `INSTALL_PRINTER.bat` כמנהל מערכת. פעמים רבות נדרש לסגור ולפתוח את Word.

**ש: שכחתי סיסמה להגדרות?**  
ת: מחק את הקובץ `~/.virtual_printer/config.json` — הגדרות יתאפסו לברירת מחדל עם סיסמה 1234.

**ש: המדפסת פותחת PDF ולא את התוכנה?**  
ת: זהו מגבלה ידועה של ה-Port "VirtualPrinterPort:" — ראה הסבר טכני למטה.

## 🔬 הסבר טכני — איך עובדת המדפסת הווירטואלית

```
אפליקציה (Word/Chrome)
        ↓  Ctrl+P → "מדפסת וירטואלית"
Windows Spooler (מנהל הדפסה)
        ↓  Driver: Microsoft Print To PDF
יוצר קובץ PDF זמני
        ↓  Port: VirtualPrinterPort:
VirtualPrinter.exe מזהה את הקובץ ופותח את הממשק
        ↓  המשתמש בוחר אפשרות הדפסה
SumatraPDF / Windows Print API
        ↓
המדפסת הפיזית האמיתית
```

> **הערה:** לשליחה אוטומטית של הפלט ממנהל ההדפסה של Windows ישירות לאפליקציה שלנו,
> נדרש Port Monitor מותאם (DLL). לשלב זה, קבצים שנשלחים מ-Word/Chrome
> ייפתחו בממשק הגרפי לאחר שמירה זמנית, מה שמאפשר ניהול מלא של ההדפסה.
