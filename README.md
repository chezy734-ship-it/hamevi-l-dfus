# מביא לדפוס — Virtual Printer

![banner](docs/banner.svg)

**גרסה 1.2** | Windows 10/11 | Python 3.10+ | PyQt6

מדפסת וירטואלית חכמה ל-Windows: שולחים הדפסה מכל תוכנה (Word, Chrome...) ובמקום ניר יוצא חלון ניהול הדפסות עם אפשרויות הדפסה חכמות בעברית — חוברת, דו-צדדי, n-up ועוד.

לחץ פעמיים על `VirtualPrinter.exe`.

לחץ פעמיים על **`INSTALL_PRINTER.bat`** (כתב-יד בארכיון ההפצה) ואשר UAC.

> ✅ אחרי ההתקנה, **"מדפסת וירטואלית"** תופיע ברשימת המדפסות של כל תוכנה ב-Windows.

## 🖨️ שימוש

### א. שליחה מתוך תוכנה אחרת
1. בכל תוכנה לחצו **הדפס** (Ctrl+P)
2. בחרו **"מדפסת וירטואלית"** מהרשימה ולחצו הדפס
3. חלון המדפסת הווירטואלית נפתח עם אפשרויות הדפסה
4. בחרו סוג הדפסה ולחצו **"הדפס עכשיו"**

### ב. פתיחה ישירה
- **גררו קובץ** לחלון התוכנה, או לחצו **"📂 בחר קובץ"**

## 🔬 איך זה עובד

```
אפליקציה (Word/Chrome)
   ↓ Ctrl+P → "מדפסת וירטואלית"
Windows Spooler (מנהל הדפסה)
   ↓ Driver: Microsoft Print To PDF
קובץ PDF זמני
   ↓ Port: VirtualPrinterPort:
VirtualPrinter.exe מזהה את הקובץ ומפתח את הממשק
   ↓ המשתמש בוחר אפשרות הדפסה
SumatraPDF / Windows Print API
   ↓
המדפסת הפיזית האמיתית
```

> **הערה טכנית:** לשליחה אוטומטית של הפלט ישירות מהספולר לאפליקציה נדרש Port Monitor מותאם (DLL). בשלב זה הקבצים נשמרים זמנית ונפתחים בממשק הגרפי — מה שמאפשר ניהול מלא של ההדפסה.

## ❓ שאלות נפוצות

**המדפסת לא מופיעה ב-Word/Chrome?** הרצו מחדש את `INSTALL_PRINTER.bat` כמנהל; לעתים יש לסגור ולפתוח את Word.

**שכחתם סיסמה להגדרות?** מחקו את `~/.virtual_printer/config.json` — ההגדרות מתאפסות עם סיסמה 1234.

**המדפסת פותחת PDF ולא את התוכנה?** מגבלה ידועה של ה-Port — ראו הסבר טכני למעלה.
